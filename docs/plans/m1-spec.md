# M1 详细规格书：零密钥离线端到端闭环

> 状态：活动规格书（M1 施工唯一依据；M1 合入 `main` 后移入 `docs/archive/`）。总览见 [路线图](roadmap.md) 与 [验收场景](../scenarios.md)。

## 1. 产品体验与反面红线

- **默认语言**：中文界面；技术专有名词（`Agent X-Ray`、`eduharness`）保留英文。
- **视觉语言与组件边界（严格执行）**：
  - 延用 `apps/web/src/index.css` 已定义的浅色点阵白板（`.dot-grid-canvas`）、深松青主色（`#0F5250`）、暖琥珀荧光高亮（`#FDE0A6`）与白色圆角浮卡。
  - **外围交互壳用 coss ui（`apps/web/src/components/ui/` 已有 7 个原语）**：`Button`、`Switch`（右上角 `Agent X-Ray`）、`Sheet`（左侧可折叠课堂记录栏 + 右侧 X-Ray 抽屉）、`Tabs`（X-Ray 内部页签）、`Badge`（状态/得分胶囊）、`Input` / `Dialog`（主题输入与离线模型提示）。
  - **核心白板区必须纯手写 Tailwind**：点阵画布、横向多栏板书卡片、荧光高亮与手绘圈画、轻量 SVG 示意图与公式卡、底部悬浮字幕与暂停/单拍/打断控制条。
- **绝对禁止（反面红线）**：
  - 禁止做成「左历史列表 + 中间一串聊天气泡」的 ChatGPT 套壳；
  - 默认学生视图禁止暴露 JSON、状态机节点、原始日志或工程调试信息；
  - 禁止一次性把整节教案文本全倒出来（必须按拍演播、可暂停、可随时打断）。

## 2. 两层动态结构与核心交互契约

### 2.1 宏观课程蓝图层（`CourseBlueprint → Unit[] → LessonRef[]`）

- **严禁写死单元数与课节数**，复用 `packages/engine/src/protocol.ts` 的 `CourseBlueprintSchema`。
- **首页双入口**：
  1. **精选示范课（2–3 节）**：至少包含 1 节呼应 `eduharness` 的数学推理示范课 + 1 节概念/技术示范课；点击后 **1 键直达第 1 节白板课**，课堂左上角提供 `← 课程蓝图` 返回查看所属单元与课节地图。
  2. **主题轻调研建课**：输入学习主题 → 完成 **2–3 步轻调研**（行内胶囊选项 + 可选补充输入，摸底基础与目标，离线确定性生成）→ 产出动态 `单元 → 课节` 蓝图 → 首节 `ready` 可点进白板课堂，其余未学课节标 `locked`（「学到这里时生成」懒生成态）。

### 2.2 单堂白板课层（`Lesson → 动态 Keypoint[] → 按拍动作流`）

- **动态要点进度条**：每堂课含 **2–6 个不等的要点（`KeypointSchema`，绝不写死 3 个）**；顶栏自适应呈现（要点少时平铺，多时紧凑折叠为进度圆点 + 当前要点名 + `当前/总数`，支持展开查看全课要点清单），仅在收到 `keypoint_complete` 后打钩。
- **按拍 SSE 演播协议**：
  - 后端严格按 `packages/engine/src/protocol.ts` 的 8 类动作（`board` / `new_column` / `new_page` / `highlight` / `graph` / `speak` / `ask` / `keypoint_complete`）经 TypeBox 校验后，通过 SSE 逐拍下发。
  - **服务端唯一权威源 + 防串流**：SQLite（`courses` / `sessions` / `session_events`）为唯一状态权威源；每次演播流携带递增 `generation` 与 `seq`，前端播完每拍回传 `last_played_step_id`。
  - 画面主舞台按栏渲染板书卡片（含深度标签与标题）、荧光高亮/手绘圈画（`highlight` / `circle`）、清晰 SVG 示意图与公式卡（`graph`）；`speak` 同步显示在底部悬浮字幕条；遇 `ask` 弹出互动卡并自动停顿等待学生作答。
- **底部悬浮控制条与打断恢复**：
  - 支持 **暂停 / 继续**、**单拍前进（Step）** 与 **随时打断插话** 输入框。
  - 学生中途发送打断消息后：服务端切新 `generation`，前端立即丢弃旧流残余事件；调用 `packages/engine/src/state.ts` 的 `truncateOnInterrupt` 截断未播动作并持久化真实 `last_played_step_id` 与打断事件，再从「实际已展示到白板上的那一拍」继续续讲。
  - **左侧可折叠课堂记录栏**：默认折叠保持画面极简，点击顶栏「课堂记录」打开左侧 `Sheet` 回看全部已播字幕、学生回答与打断截断点；刷新页面后从 SQLite 精确恢复白板卡片、要点进度、记录栏与打断上下文。

### 2.3 `Agent X-Ray` 工程透视与离线 6 维质检

- 默认关闭；打开右上角 `Agent X-Ray` `Switch` 后，右侧展示工程透视抽屉（约占 25%–30% 视口宽度），左侧白板自适应重排并在卡片与字幕上浮出 `#1 / #2 / #3...` 证据角标。
- 右侧透视抽屉用 `Tabs` 提供 3 个视图：
  1. **动作流与状态机**：实时展示动作队列、`TeachingState`（`intake → diagnose → scaffold → handoff → verify → completed`）与已播/截断步数；
  2. **公开对话投影与追踪**：复用 `projectActionsToPublicDialogue` 展示 `#n` 编号公开对话及离线耗时/步骤追踪；
  3. **`eduharness` 6 维质检**：一键触发离线确定性 6 维质检（返回 6 维得分胶囊与证据锚点 `[#n]`），点击任意 `#n` 时左侧对应白板卡片（按 `evidenceStepIds` 关联）与字幕条目同步高亮并滚动定位。

## 3. 切片清单与顺序（供秘书拆入 Todo 接力推进）

按依赖顺序拆为 **4 个可独立黑盒验收的切片**（均遵守单文件 ≤ 360 行、零显式 `any`、三层导入隔离）：

1. **M1-1 · 双入口与两层动态课程蓝图**
   - 交付：离线示范课夹具 + 轻调研与蓝图生成纯引擎逻辑 + Hono REST API（课程列表、示范课直达、轻调研生成、蓝图查询，入参按 TypeBox 校验）+ SQLite 持久化 + 首页双入口与课程蓝图页（含 `locked` 懒生成态与 `← 课程蓝图` 返回）。
   - 黑盒验收：真实浏览器验证 1 键进示范课白板入口 + 返回蓝图 + 走完 2–3 步轻调研生成动态单元与课节并点亮首节，确认零控制台报错并截图留证。
   - 不算交付：仅返回 mock JSON 但前端未真实联调或刷新后课程丢失。
2. **M1-2 · 按拍 SSE 白板演播与动态要点**（依赖 M1-1）
   - 交付：服务端 SSE 按拍流（带 `generation` / `seq`）与进度回传接口 + 前端纯手写 Tailwind 多栏白板（`board` / `highlight` / `circle` / `graph` SVG+公式 / `ask` 停顿）+ 底部悬浮字幕条（暂停/继续/单拍）+ 顶栏自适应动态要点进度条（`keypoint_complete` 打钩）。
   - 黑盒验收：真实浏览器启动示范课，观察逐拍出现板书、荧光高亮/圈画、SVG 图示、字幕与 `ask` 停顿；实测暂停/单拍推进与回答后要点打钩，确认零报错并截图留证。
   - 不算交付：整段文本一次性静默渲染、写死 3 个要点、或把板书塞进聊天气泡。
3. **M1-3 · 左侧记录栏、打断截断与 SQLite 刷新恢复**（依赖 M1-2）
   - 交付：左侧默认折叠 `Sheet` 课堂记录栏 + 演播中途打断接口（切新 `generation` + `truncateOnInterrupt` 截断未播拍 + 从已播点续讲）+ 会话快照持久化与页面刷新精确恢复。
   - 黑盒验收：真实浏览器演播中途发送打断消息，确认旧流停止、未播拍被截断、新续讲接上；展开左侧记录栏看到完整字幕与打断记录；整页刷新后白板卡片、要点进度与记录栏与刷新前一致并截图留证。
   - 不算交付：刷新后回到初始空态、或打断后旧流卡片继续冒出。
4. **M1-4 · `Agent X-Ray` 离线 6 维质检、`#n` 高亮联动与 Playwright E2E 固封**（依赖 M1-3）
   - 交付：纯引擎离线 6 维确定性评估夹具 + 服务端质检接口 + 前端 X-Ray 3 页签抽屉、卡片/字幕 `#n` 角标与点击双向高亮定位 + Playwright 真实浏览器全链路 E2E 测试脚本并接入验真。
   - 黑盒验收：真实浏览器开启 X-Ray → 一键跑 6 维质检 → 点击评分证据 `#n` 确认左侧对应板书卡片与字幕同步高亮并截图留证；Playwright 全链路 E2E 与 `npm run check` 全绿。
   - 不算交付：无真实浏览器 E2E、或点击 `#n` 无对应卡片/字幕高亮定位。
