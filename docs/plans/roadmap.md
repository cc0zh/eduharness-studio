# 分阶段路线图（M0–M3）

总原则：**越轻量越好**（不做登录注册、外部数据库、TTS、自由手绘或重运维），每个里程碑以真实端到端 E2E 验收为核心。

## M0（已完成）：Day-1 骨架与门禁

- 三层仓库结构（`packages/engine`、`apps/server`、`apps/web`）与基础纯引擎契约。
- 文档骨架与防堆放 Lint、三层导入边界 Lint、`npm run check` 与 CI。
- 一键 `npm run dev` 并行拉起前后端最小页面与 M0 E2E 连通冒烟。

## M1（已完成）：零密钥离线端到端闭环（详细契约与切片见 [M1 详细规格书](../archive/m1-spec.md)）

- 精选示范课一键直达 + 2–3 步轻调研生成动态两层课程蓝图（后续课节懒生成）。
- 分栏白板按拍 SSE 演播（板书、荧光高亮/圈画、SVG 示意图、底部字幕、`ask` 停顿、动态要点进度条）。
- 左侧可折叠课堂记录栏、暂停/单拍/中途打断截断与 SQLite 刷新恢复。
- `Agent X-Ray` 工程抽屉 + 离线 6 维质检 + `#n` 证据回绑高亮，以及 Playwright 浏览器 E2E 测试。

## M2（下一步）：真实模型与自由主题建课

- 后端只在 `packages/engine/src/models.ts` 接入统一模型边界（`@earendil-works/pi-ai`）替换 M1 离线剧本，支持 `.env`（含 `HTTPS_PROXY` 代理）与内存态临时 BYOK Key（密钥绝不落库或写日志）。
- **教师引擎执行架构**：采用单循环状态机护栏（重点保 `verify` 过关门禁，不做多轮 UI Tool-Calling）+ 受控真实计算工具（如 `calc_verify`，X-Ray 展示耗时）+ 统一按拍事件流抽象；先跑稳单次 JSON 批量生成按拍推 SSE，若实测首拍等待超过 2 秒再平滑升级流式逐拍解析（前端零改动）。
- 前端基本沿用 M1 契约与页面，仅开放顶栏临时 BYOK 弹窗，并支持有 Key 时在 X-Ray 按需一键对当前白板课触发 1 次真实质检；自由输入任意主题跑通轻调研 → 动态两层蓝图 → 实时状态机教学、工具验算与打断续讲（经预算授权后做真实冒烟）。

## M3：`eduharness` 双轨轻量闭环与收官

- 补齐 CLI 适配脚本，通过白板→公开对话投影层（按师生回合归并）接回 `eduharness` 跑真实批量回归验真并留存证据（**绝不修改 `eduharness` 原库**），验证白板形态未退化为单向长讲、过早揭底或丢失验证（V 维）。
- 收口精简 [README](../../README.md) 与双项目展示。
