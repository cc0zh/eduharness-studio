# 分阶段 E2E 验收场景

本项目以端到端场景验收为主，纯逻辑硬边界配精简单测。详见 [路线图](plans/roadmap.md)。

## M0：骨架与门禁

- **场景 M0-1（门禁全绿）**：执行 `npm run check`，依次通过三层导入边界、文档 Lint、前后端类型检查、前端构建、纯引擎单测、门禁负例单测与前后端连通 E2E 冒烟测试。
- **场景 M0-2（一键开发启动）**：执行 `npm run dev` 同时拉起 Hono 后端与 Vite 前端，访问页面显示本地 SQLite 健康连接状态，且可切换 `Agent X-Ray` 抽屉。

## M1：零密钥离线端到端闭环

- **场景 M1-1（两层入口与建课）**：一键打开精选示范课进入白板，或输入主题完成 2–3 步轻调研生成动态 `单元 → 课节` 蓝图并点击就绪课节进入课堂（其余课节保持懒生成锁态）。
- **场景 M1-2（按拍白板演播）**：SSE 逐拍渲染板书卡片、荧光高亮/圈画、SVG 示意图、底部口语字幕与 `ask` 互动停顿；支持暂停、单拍推进与动态要点过关打钩。
- **场景 M1-3（记录栏与打断持久化）**：展开左侧可折叠课堂记录栏回看轨迹；在演播中途发送打断消息截断未播拍，刷新页面后从 SQLite 精确恢复到已播状态与打断上下文。
- **场景 M1-4（X-Ray 6 维质检联动）**：开启 `Agent X-Ray`，一键触发离线 6 维质检，点击评分证据 `#n` 时左侧对应白板卡片与字幕同步高亮定位。

## M1.5：前端视觉重构与配图样板

- **场景 M1.5-1（中文视觉与交互重构）**：在保持既有两层入口、按拍演播、`ask`/打断焦点互斥与 X-Ray 跨页高亮的前提下，完成新版白板视觉落地并敲定 M2 配图方案，既有 Playwright E2E 与 `npm run check` 全绿。

## M2：真实模型与完整课堂闭环

- **场景 M2-1（自由建课与懒生成解锁）**：通过 `.env` 或页面临时 BYOK Key 经 `packages/engine/src/models.ts`（复用 `@earendil-works/pi-ai`）接入真实模型，自由输入主题完成轻调研与动态蓝图，支持点击解锁 `locked` 后续课节，并在无 Key 时平滑回落离线模式。
- **场景 M2-2（认知规划与打断续讲）**：faux Chromium 跑通点选 → 变式自答 → 过关、卡壳插入补课要点且刷新可见、首轮敷衍降级二选一及连续敷衍记为未验证；打断后从已上屏拍续讲。Loopback OpenAI-compatible Chromium 通过 BYOK 拉取模型后触发 Teacher Agent，`pi-ai` 最多两步工具循环实际调用 `calc_verify` 并把结果回传后再生成结构化回合。X-Ray 展示诊断、状态机拦截重试及脱敏工具输入/结果/耗时。日常门禁零外网和付费；真实试学仍须先获预算授权。
- **场景 M2-4（真机功能冒烟与配图降级）**：同一浏览器脚本先通过零外网完整预演和模拟 502，再在明确预算内完成真机建课、第 2 节懒解锁、作答、按 `last_played_step_id` 打断续讲及刷新。X-Ray 核对诊断、护栏与模型耗时；主题触发 `calc_verify` 时核对工具调用、结果及耗时。配图失败时验证文字保底，保留截图和脱敏收据，区分真机与离线证据。[已执行证据](status.md#m2-4-真机冒烟)

## M2.5：语义分镜编译

- **场景 M2.5-1（离线纯引擎切片）**：faux 和 loopback 只交教学分镜；开场、插话、近迁移与敷衍回合的输出 Schema 和 Prompt 字段骨架同源裁剪。编译器确定性展开过关反馈、逐块板书与字幕及末拍提问；轻格式噪声不重试，非法过关、泄密和开场揭底仍被拦截。`calc_verify` 用完两步后仍有单独交卷，工作记忆只保留最近四条已上屏的过关结论；末要点先过关、后回顾，打断不把待播回顾算进投影。
- **场景 M2.5-2（首课真规划与恢复）**：用 loopback faux 建课，点击仍标为就绪的 `u1-l1`，Chromium 白板显示与主题相关的 2–4 个递进要点和已上屏开场。刷新恢复同一课节、会话与已上屏拍，不再请求模型。API 回归在并发请求和独立 SQLite 连接上验证防重，非法规划不写入占位会话；无 Key 与精选示范课保留原定稿。

## M3：`eduharness-ts` 真评测闭环与收官

- **场景 M3-1（`judge-only` 真实回归验真）**：通过只读 SQLite CLI（`npm run export:judge`）将确认上屏的公开对话投影送入 `eduharness-ts --judge-only`，离线全通并经预算授权完成真机 `live-02`（Studio 19/114 POST、ts 12/72 次、`--verify-run` `verified=true` 与 Chrome 离线 HTML `#n` 高亮核验），诚实记录内容与脚本边界并收口 `README.md`。[已执行证据](status.md#m3-验收证据)
