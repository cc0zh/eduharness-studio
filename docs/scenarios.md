# 分阶段 E2E 验收场景

本项目以端到端场景验收为主，纯逻辑硬边界配精简单测。详见 [路线图](plans/roadmap.md)。

## M0：骨架与门禁

- **场景 M0-1（门禁全绿）**：执行 `npm run check`，依次通过三层导入边界、文档 Lint、前后端类型检查、前端构建、纯引擎单测、门禁负例单测与前后端连通 E2E 冒烟测试。
- **场景 M0-2（一键开发启动）**：执行 `npm run dev` 同时拉起 Hono 后端与 Vite 前端，访问页面显示本地 SQLite 健康连接状态，且可切换 `Agent X-Ray` 抽屉。

## M1：零密钥离线端到端闭环

- **场景 M1-1（两层入口与建课）**：一键打开精选示范课进入白板，或输入主题完成 2–3 步轻调研生成动态 `单元 → 课节` 蓝图并点击就绪课节进入课堂（其余课节保持懒生成锁态）。
- **场景 M1-2（按拍白板演播）**：SSE 逐拍渲染板书卡片、荧光高亮/圈画、SVG 示意图、底部口语字幕与 `ask` 互动停顿；支持暂停、单拍推进与动态要点过关打钩。
- **场景 M1-3（记录栏与打断持久化）**：展开左侧可折叠课堂记录栏回看轨迹；在演播中途发送打断消息截断未播拍，刷新页面后从 SQLite 精确恢复到已播状态与打断上下文。
- **场景 M1-4（X-Ray 6 维质检联动）**：开启 `Agent X-Ray`，一键触发离线 6 维质检，点击评分证据 `#n` 时左侧对应白板卡片与字幕同步高亮定位。

## M2：真实模型与自由主题建课

- **场景 M2-1**：通过 `.env` 或页面临时 BYOK Key 接入统一模型网关（`packages/engine/src/models.ts`），自由输入主题跑通动态蓝图、实时状态机教学、工具验算与打断续讲（须获明确预算授权后运行真实冒烟）。

## M3：`eduharness` 门禁实打通与收官

- **场景 M3-1**：通过白板→公开对话投影层将教学引擎接入 `eduharness` 跑真实回归验真并留存证据，收口精简 `README.md`。
