# M1.5 详细规格书：前端视觉重构、交互打磨与配图定案

> 状态：已归档（M1.5 视觉 Token、三屏去套框布局与 M2 配图方案已全部拍板并落地）。总览见 [路线图](../plans/roadmap.md) 与 [验收场景](../scenarios.md)。

## 1. 定位与视觉边界（固定骨架 vs 自由发挥）

本阶段**零模型费用**，只重构前端展示与交互手感（`apps/web`），不破坏既有纯引擎契约、SSE 按拍协议、SQLite 恢复与 M1 全量 Playwright E2E 行为。

### 1.1 必须锁死的骨架与红线

- **三页两层结构**：
  - 首页：主题输入框（原地展开 2–3 步轻调研胶囊）+ 2 张精选示范课直达卡（贝叶斯 3 要点 / Transformer 5 要点）+ 可选「我的课程」列表；
  - 课程蓝图页：动态数量 `单元 → 课节`，清晰区分 `ready` / `completed` 与 `locked`（「学到这里时生成」懒生成态）；
  - 白板课堂页：顶栏（返回蓝图、课节名、左侧可折叠「课堂记录」、自适应 2–6 动态要点进度条、模型/BYOK 预留入口、重来、默认关闭的 `Agent X-Ray` 开关）+ 主舞台（横向 2–3 栏可回翻多页白板，承载板书/`highlight`/`circle`/KaTeX 公式/示意图 `graph`/`ask` 停顿）+ 底部无 TTS 字幕与暂停/单拍/打断控制区 + 默认关闭的右侧 `Agent X-Ray` 3 页签抽屉与 `#n` 跨页高亮。
- **组件与反面红线**：外围壳沿用 `apps/web/src/components/ui/` 既有 coss ui 原语，核心白板保持纯手写 Tailwind；严禁做成聊天气泡页、一次性倒出全文、放真人照片头像、或引入登录/语音 TTS/自由画笔工具栏。

### 1.2 已定稿的视觉系统（出版书房融合版）

- **色板 Token 与材质**：象牙棉纸主画布 `#F6F3EC`（配离线 `1.8%` SVG 棉纸噪点，零点阵冷灰）、表面 `#FBF9F4`、暖石审稿抽屉 `#ECE8DF`、发丝细线 `#DDD6C8` / `#BFB6A6`、浓炭墨 `#1A1917` / `#4D4943` / `#827B71`、唯一批注强调色焦赭赤陶 `#A84428`、干橄榄完成态 `#4A5B44`、羊皮琥珀荧光洗色 `rgba(214, 174, 92, 0.32)`；彻底清零旧冷灰与软件蓝绿。
- **中文排版与离线字体栈**：大标题/课节名/图注采用现代人文衬线栈 `"Georgia", "Noto Serif SC", "Source Han Serif SC", "Songti SC", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei UI", sans-serif`（零外网 CDN，Windows 下绝不退回锯齿 `SimSun`），正文采用现代中文无衬线 `"Noto Sans SC", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei UI", sans-serif`（行高 `1.8–1.82`）。
- **容器与 X-Ray 反差策略**：首页采用居中安静书刊扉页 + `14px` 柔和微圆角棉纸主题输入台 + 无外框纯排版 `01/02` 典籍示范课；白板舞台整屏铺开纯净纸面、极细发丝竖线分栏与去套娃内容排版；`Agent X-Ray` 采用**同色系暖石编辑校样栏（`#ECE8DF`）**配赤陶 `#n` 页边锚点，全局光线统一无明暗割裂。

## 2. 必落地的 6 项交互与体验升级

1. **无 TTS 的演播节奏感**：单拍上屏配克制渐显过渡（`200–300ms`），`highlight` 做左向右扫过、`circle` 做手绘描边；去掉每拍焦虑倒计时进度条，改为按上一拍内容量自适应的舒缓阅读节拍（首拍即出，长板书/图解/长字幕约 `2.4–4.5s`），支持 `Space` 暂停/继续与 `→`（演播中亦可）随时提前单拍推进。
2. **`ask` 与打断焦点互斥**：平时仅底部打断框可输入；遇 `ask` 停顿时白板内就地展开答题区并自动聚焦，底部条切换为「等待白板作答」避免双输入框冲突；提交后答案留在原位并继续演播。
3. **跨页回看与 `#n` 定位不迷路**：回看历史页时提供醒目轻提示「回到最新页」；点击 X-Ray 证据 `#n` 跨页跳回后平滑滚入视口并亮起定位高亮。
4. **中文板书可读性分层**：支持安全轻结构排版（要点列表、关键词加粗与紧凑对比表，纯 AST/结构渲染严禁原始 HTML 注入），控制单栏舒适字宽，避免大段纯文本堆块。
5. **异步等待态占位（为 M2 铺路）**：为自由主题建课、点击解锁 `locked` 懒生成课节及 M2 后台出图准备克制的局部骨架占位态，不白屏也不打断阅读。
6. **X-Ray 舞台平滑让位**：右侧抽屉占 25%–30% 宽滑出时左侧白板流畅自适应，不挤碎卡片或遮挡正文，关闭即回到极简纯净学生态。

## 3. 配图机制选型结论（已回填 M2）

经 2 节示范课真实中文语境比选，最终拍板**方案 A：分工画图 + 预设统一画风静态 SVG**（详见 [m2-spec.md](m2-spec.md#24-白板配图graph生成机制m15-已定案)）：

- **选定理由**：在既有 `static-svg` 严格白名单消毒下即可稳定呈现**Tufte 铜版学术图版**画风（象牙纸底 `#F6F3EC`、炭黑/赤陶细斜线排线、标尺与单色焦距），零脚本、零沙箱 iframe 复杂度、高分屏矢量锐利且天然融入去套框白板纸面。
- **不选方案 B/C**：沙箱动效卡会增加 CSP 与交互焦点复杂度；纯确定性模板表现力受限于固定拓扑，难以覆盖自由主题多样图解。

## 4. 切片清单与验收顺序

均须遵守单文件 ≤ 360 行、零显式 `any`、零外网字体/资源依赖与 `pnpm run check` 全绿：

1. **M1.5-1 · 视觉定稿、主题 Token 与原语换肤**（依赖网页端视觉定稿）
   - **交付**：回填第 1.2 节定稿，更新 [apps/web/index.html](../../apps/web/index.html)、[apps/web/src/index.css](../../apps/web/src/index.css) 与 7 个 coss ui 原语，彻底清零旧冷灰硬编码。
   - **黑盒验收**：首页、蓝图页与白板页零旧色残留，Windows 本地浏览器中文无 `SimSun` 回退，`pnpm run check:static` 全绿。
   - **不算交付**：仅改 CSS 变量但组件内残留大量硬编码旧色或依赖外网 CDN 字体。
2. **M1.5-2 · 三屏布局重构与 6 项交互升级**（依赖 M1.5-1）
   - **交付**：重构首页、课程蓝图、分栏白板（含安全轻结构板书、`ask`/打断焦点互斥、快捷键与等待态占位）、底部演播条及 `Agent X-Ray` 抽屉。
   - **黑盒验收**：真实浏览器走通贝叶斯（2 栏 / 3 要点）与 Transformer（3 栏 / 5 要点折叠）演播、翻页、打断、作答与 X-Ray `#n` 跨页高亮；既有 Playwright 全链路回归全绿。
   - **不算交付**：出现双输入框抢焦点、X-Ray 展开挤碎卡片、或破坏刷新恢复与上屏证据测试。
3. **M1.5-3 · 示范课配图统一、M2 配图定案与视觉验收收口**（依赖 M1.5-2）
   - **交付**：按新色板统一 2 节示范课 SVG 配图，将选定的配图方案回填 [m2-spec.md](m2-spec.md#24-白板配图graph生成机制m15-已定案)，在真实 Chrome 截取三屏 + X-Ray 联动截图存 `C:\tmp\eduharness-studio\m1.5\`，清理临时静态原型并跑通全量 `pnpm run check`。
   - **黑盒验收**：人工复看中文真实渲染截图确认无排版发闷或错位，`pnpm run check` 退出 0。
   - **不算交付**：未做真实浏览器复看、未回填 M2 配图结论、或遗留未清理的临时调试控件。
