# M1 详细规格书：零密钥离线端到端闭环

> M1 阶段规格已归档。查看 [路线图](../plans/roadmap.md) · [验收场景](../scenarios.md) · [交付证据](../status.md#m1-验收证据)。

## 1. 产品体验与反面红线

- **默认语言**：中文界面；技术专有名词（`Agent X-Ray`、`eduharness`）保留英文。
- **视觉语言与组件边界（严格执行）**：
  - 延用 `apps/web/src/index.css` 已定义的浅色点阵白板（`.dot-grid-canvas`）、深松青主色（`#0F5250`）、暖琥珀荧光高亮（`#FDE0A6`）与白色圆角浮卡。
  - **外围交互壳用 coss ui（`apps/web/src/components/ui/` 已有 7 个原语）**：`Button`、`Switch`（右上角 `Agent X-Ray`）、`Sheet`（左侧可折叠课堂记录栏 + 右侧 X-Ray 抽屉）、`Tabs`（X-Ray 内部页签）、`Badge`（状态/得分胶囊）、`Input` / `Dialog`（主题输入与离线模型提示）。
  - **核心白板区必须纯手写 Tailwind**：点阵画布、横向 2–3 栏可回翻分页板书卡片、荧光高亮与手绘圈画、KaTeX 数学公式与白名单消毒 SVG 示意图、底部悬浮字幕与暂停/单拍/打断控制条。
- **绝对禁止（反面红线）**：
  - 禁止做成「左历史列表 + 中间一串聊天气泡」的 ChatGPT 套壳；
  - 默认学生视图禁止暴露 JSON、状态机节点、原始日志或工程调试信息；
  - 禁止一次性把整节教案文本全倒出来（必须按拍演播、可暂停、可随时打断）。

## 2. 两层动态结构与核心交互契约

### 2.1 宏观课程蓝图层（`CourseBlueprint → Unit[] → LessonRef[]`）

- **严禁写死单元数与课节数**，复用 `packages/engine/src/protocol.ts` 的 `CourseBlueprintSchema`。
- **首页双入口**：
  1. **精选示范课（2 节精雕）**：
     - **「条件概率与贝叶斯直觉」**（**3 个动态要点**，平铺进度条）：面积方块 SVG 表征转换、KaTeX 贝叶斯公式、直觉误解修复、`ask` 防剧透停顿与 `new_page` 迁移练习，强呼应 `eduharness` 6 维质检；
     - **「Transformer 自注意力机制」**（**5 个动态要点**，紧凑折叠进度条）：Q/K/V 权重流向 SVG、KaTeX 缩放点积公式、多栏板书与 `new_page` 翻页，展示硬核技术通俗讲解；
     - 点击后 **1 键直达第 1 节白板课**，课堂左上角提供 `← 课程蓝图` 返回查看所属单元与课节地图。
  2. **主题轻调研建课**：输入学习主题 → 完成 **2–3 步轻调研**（行内胶囊选项 + 可选补充输入，摸底基础与目标，离线确定性生成并在 UI 坦诚标注离线模式）→ 产出动态 `单元 → 课节` 蓝图 → 首节 `ready` 可点进白板课堂，其余未学课节标 `locked`（「学到这里时生成」懒生成态）。

### 2.2 单堂白板课层（`Lesson → 动态 Keypoint[] → 按拍动作流`）

- **动态要点进度条**：每堂课含 **2–6 个不等的要点（`KeypointSchema`，绝不写死 3 个）**；顶栏自适应呈现（要点少时平铺，多时紧凑折叠为进度圆点 + 当前要点名 + `当前/总数`，支持展开查看全课要点清单），仅在收到 `keypoint_complete` 后打钩。
- **按拍 SSE 演播协议与白板渲染契约**：
  - 后端严格按 `packages/engine/src/protocol.ts` 的 8 类动作（`board` / `new_column` / `new_page` / `highlight` / `graph` / `speak` / `ask` / `keypoint_complete`）经 TypeBox 校验后，通过 SSE 逐拍下发（保持统一按拍事件流抽象，便于 M2 无缝替换为真模型流）。
  - **服务端唯一权威源 + 防串流**：SQLite（`courses` / `sessions` / `session_events`）为唯一状态权威源；每次演播流携带递增 `generation` 与 `seq`，前端播完每拍回传 `last_played_step_id`。
  - **多栏可回翻分页与公式/图示安全**：单页支持横向 2–3 栏（开启右侧 X-Ray 抽屉时自适应/横向滚动不挤碎卡片），遇 `new_page` **保留全部历史页**并提供极简「第 X/Y 页」切换（默认跟随最新页，允许回翻，也为 `#n` 跨页定位铺路）；前端引入轻量 **KaTeX** 渲染公式；`graph` 保留 `svg_markup` 并做静态白名单消毒（禁 `<script>` / `<foreignObject>` / `on*` / 外链 `href`，要求规范 `viewBox`），同时在 `GraphActionSchema` 预留可选结构化 `diagram` 字段供 M2 扩展。
  - `speak` 同步显示在底部悬浮字幕条；遇 `ask` 弹出互动卡并自动停顿等待学生作答。
- **底部悬浮控制条、意图分支打断与 SQLite 刷新恢复**：
  - 支持 **暂停 / 继续**、**单拍前进（Step）** 与 **随时打断插话** 输入框。
  - **可截断动态队列与意图分支续讲**：学生中途打断时，前端必须显式携带**实际已上屏的 `last_played_step_id`**（不可误把服务端刚发出但尚未上屏的拍算作已播），且区分“自己主动打断切流”与“异端顶号 `superseded`”；服务端切新 `generation` → 调用 `truncateOnInterrupt` 截断未播拍 → 按 **2–3 类关键词意图**（追问原理/换表征、伸手要答案触发防剧透脚手架、常规承接）追加新续讲 `ActionBatch`（新 `step_id` 严格递增且不引用已截断 `card_id`），并**真实驱动 `TeachingState` 跃迁**（显式强化 `verify` 检验后才触发 `keypoint_complete` / `completed`）。
  - **左侧可折叠课堂记录栏与会话复用恢复**：默认折叠保持画面极简，点击顶栏「课堂记录」打开左侧 `Sheet` 回看全部已播字幕、学生回答与打断截断点；刷新页面时**复用当前课节最近活跃会话**（不可每次刷新新建空会话；提供显式「重新开始」按钮），从 SQLite 精确恢复多页白板卡片、要点进度、状态机、记录栏与打断上下文。

### 2.3 `Agent X-Ray` 工程透视与离线 6 维质检

- 默认关闭；打开右上角 `Agent X-Ray` `Switch` 后，右侧展示工程透视抽屉（约占 25%–30% 视口宽度），左侧白板自适应重排并在卡片与字幕上浮出 `#1 / #2 / #3...` 证据角标。
- **公开对话按师生回合归并**：在 `packages/engine` 提供纯函数，将两次学生输入（`answer` / `interrupt`）之间实际已播的连续教师动作合并为 1 个 `teacher_turn`，再经 `projectActionsToPublicDialogue` 产出标准师生交替 `#1 / #2 / ...` 编号（禁止把每单拍拆成独立 `#n`），并与 `eduharness` 6 维尺子对齐。
- 右侧透视抽屉用 `Tabs` 提供 3 个视图：
  1. **动作流与状态机**：实时展示动作队列、`TeachingState`（`intake → diagnose → scaffold → handoff → verify → completed`）真实跃迁与已播/截断步数；
  2. **公开对话投影与追踪**：展示归并后的 `#n` 公开对话及离线耗时/步骤追踪（为 M2 `calc_verify` 等受控计算工具耗时预留结构）；
  3. **`eduharness` 6 维质检**：一键触发离线确定性 6 维质检（返回 6 维得分胶囊与证据锚点 `[#n]`），点击任意 `#n` 时能**跨页自动切回**对应白板页并同步高亮滚动定位关联卡片（按 `evidenceStepIds`）与字幕条目。

## 3. 切片清单与顺序（供秘书拆入 Todo 接力推进）

按依赖顺序拆为 **4 个可独立黑盒验收的切片**（均遵守单文件 ≤ 360 行、零显式 `any`、三层导入隔离）：

1. **M1-1 · 双入口与两层动态课程蓝图**
   - 交付：离线示范课夹具 + 轻调研与蓝图生成纯引擎逻辑 + Hono REST API（课程列表、示范课直达、轻调研生成、蓝图查询，入参按 TypeBox 校验）+ SQLite 持久化 + 首页双入口与课程蓝图页（含 `locked` 懒生成态与 `← 课程蓝图` 返回）。
   - 黑盒验收：真实浏览器验证 1 键进示范课白板入口 + 返回蓝图 + 走完 2–3 步轻调研生成动态单元与课节并点亮首节，确认零控制台报错并截图留证。
   - 不算交付：仅返回 mock JSON 但前端未真实联调或刷新后课程丢失。
2. **M1-2 · 按拍 SSE 白板演播、多页回翻与 KaTeX/SVG**（依赖 M1-1）
   - 交付：服务端 SSE 按拍流（带 `generation` / `seq` 与背压）与进度回传接口 + 前端纯手写 Tailwind 多栏可回翻白板（保留历史页与「第 X/Y 页」切换、`board` / `highlight` / `circle` / KaTeX 公式 + 白名单消毒 SVG `graph` + `diagram` 预留字段 / `ask` 停顿）+ 底部悬浮字幕条（暂停/继续/单拍）+ 顶栏自适应动态要点进度条（3 要点平铺、5 要点紧凑折叠，`keypoint_complete` 打钩）+ 2 节精雕示范课（「条件概率与贝叶斯直觉」与「Transformer 自注意力机制」）。
   - 黑盒验收：真实浏览器启动两节示范课，观察逐拍出现板书、荧光高亮/圈画、KaTeX 公式、SVG 图示、字幕、`ask` 停顿与 `new_page` 回翻；实测暂停/单拍推进与回答后要点打钩，确认零报错并截图留证。
   - 不算交付：整段文本一次性静默渲染、遇 `new_page` 丢弃旧页、写死 3 个要点、或把板书塞进聊天气泡。
3. **M1-3 · 左侧记录栏、意图分支打断与 SQLite 刷新恢复**（依赖 M1-2）
   - 交付：拆出独立组件与存储模块（严守单文件 ≤ 360 行）；左侧默认折叠 `Sheet` 课堂记录栏 + 可截断动态队列与随时打断接口（显式传上屏 `last_played_step_id`、区分主动打断与 `superseded`、`truncateOnInterrupt` 截断 + 2–3 类意图分支续讲 + 真实 `TeachingState` 状态机跃迁与 `verify` 护栏）+ 课节活跃会话复用与整页刷新精确恢复（另提供显式「重新开始」）。
   - 黑盒验收：真实浏览器演播中途发送不同意图打断消息（如追问原理 / 直接要答案），确认旧流无误报停止、未播拍被截断、对应分支续讲接上；展开左侧记录栏看到完整字幕与打断记录；整页刷新后多页白板卡片、要点进度与记录栏与刷新前一致并截图留证。
   - 不算交付：刷新后新建空白会话、打断误触发 `superseded` 报错、或旧流卡片继续冒出。
4. **M1-4 · `Agent X-Ray` 离线 6 维质检、跨页 `#n` 联动与 Playwright E2E 固封**（依赖 M1-3）
   - 交付：纯引擎「逐拍事件→师生回合归并」与离线 6 维确定性评估模块 + 服务端质检接口 + 前端顶栏开关与 X-Ray 3 页签抽屉（展开时左侧白板自适应重排）、卡片/字幕 `#n` 角标与跨页点击双向高亮定位 + Playwright 真实浏览器全链路 E2E 测试（使用随机空闲端口与独立临时 SQLite 并自动清理进程）。
   - 黑盒验收：真实浏览器播过翻页后开启 X-Ray → 一键跑 6 维质检 → 点击指向第 1 页的评分证据 `#n` 确认白板自动翻回并同步高亮对应卡片与字幕并截图留证；Playwright 全链路 E2E 与 `pnpm run check` 全绿。
   - 不算交付：无真实浏览器 E2E、1 拍拆成 1 条 `#n`、或点击 `#n` 无法跨页高亮定位。

## 4. M1 明确不做项（Out of Scope）

- 不接入真实付费 LLM API，不启用 BYOK 真实请求（留 M2）；
- 不做登录鉴权、外部数据库、语音 TTS、自由手绘白板或重运维；
- 不修改兄弟仓库（`eduharness`、`mini-eduharness2`、`mini-hyperknow1`、`resume`）。
