# eduharness-studio（TeachArena 课堂）

面向 1 对 1 交互式学习的轻量分栏白板课堂与工程透视工作室，与评测门禁仓库 `eduharness` 组成双项目组合。

## 核心体验

1. **轻量两层学习结构**：输入任意主题经轻调研生成动态 `课程 → 单元 → 课节` 蓝图（后续课节按需懒生成），也提供精选示范课一键直达单节白板课。
2. **分栏白板按拍演播（无 TTS）**：主舞台为点阵分栏白板，按拍演播板书、荧光高亮/圈画、SVG 示意图、口语字幕与 `ask` 互动停顿；支持左侧可折叠课堂记录栏、暂停/单拍推进与随时打断续讲，并由本地 `node:sqlite` 持久化已播状态。
3. **一键 `Agent X-Ray` 工程透视**：默认学生界面极简纯净；开启后右侧滑出工程抽屉，实时查看动作流队列、教学状态机、白板→公开对话投影与工具耗时，并支持一键触发 `eduharness` 6 维质检与 `#n` 联动高亮。

## 三层架构

| 层级     | 目录              | 职责与边界                                                                                |
| :------- | :---------------- | :---------------------------------------------------------------------------------------- |
| 纯引擎层 | `packages/engine` | 动作流与蓝图 TypeBox 契约、状态机、打断截断、白板→公开对话投影；零 React/HTTP/SQLite 依赖 |
| 服务端   | `apps/server`     | Node 22 + Hono + `node:sqlite` 本地持久化与 SSE 下发；严禁导入前端或模型 SDK              |
| 前端     | `apps/web`        | React + Vite + Tailwind 点阵白板与 X-Ray 抽屉；仅引用浏览器安全引擎导出                   |

## 快速开始

```bash
npm ci
npm run check
npm run dev
```

默认零密钥离线运行（无需 `.env`）；`npm run dev` 同时启动本地后端（`http://127.0.0.1:3001`）与前端（`http://127.0.0.1:5173`）。
